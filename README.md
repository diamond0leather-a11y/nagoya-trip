2. このフォルダ内のindex.html、style.css、data.js、clock.js、app.js、assetsフォルダ、.nojekyllをリポジトリの直下に配置。
3. リポジトリのSettings → Pages → Deploy from a branchでmain、/(root)を選択して保存。
4. 発行されたURLを5名に共有。
